# 小说发布网站

这是一个基于 Next.js、Contentlayer、Tailwind CSS 和 ImageKit 的简易小说发布网站。页面内容由 ImageKit 远程提供，小说正文不进入代码仓库。

## 页面功能

- 首页与小说页面 `/novels` 从 ImageKit 展示小说列表。
- 点击小说标题展开完整简介，通过“章节目录”展开章节列表。
- 点击章节标题进入正文阅读页。
- 正文页提供上一章、下一章、返回目录和下载本章。
- 关于页面介绍小说发布品牌。
- 图片按年份/月目录存放，可通过独立 URL 展示图片和文件名。
- 声音页面 `/media` 按日期展示 ImageKit 音频，支持播放/暂停、进度、上一首/下一首、自动续播、循环与定时停止。

图片目录和 URL 规则请参考 [public/images/README.md](./public/images/README.md)。

## 中英文界面

顶栏的 `EN` / `中文` 按钮切换界面语言，默认中文。语言偏好保存在 `snowfall-locale` Cookie 中，有效期一年；服务端首屏、页面标题与描述同步采用所选语言。切换保持当前 URL、阅读位置和播放器状态。

导航、页面介绍、作品状态、章节导航、阅读设置、播放器、加载及错误提示均支持中英文。小说正文、作品简介和原始音频标题保留作者提供的语言。

文案集中在 `lib/i18n/messages.ts`，英文与中文使用相同的类型化键名。新界面文案应通过 `Text` 或 `useLocale().t` 展示；服务端使用 `getTranslations`。关于页面的中英文介绍也在这份文案表中维护。

执行 `node scripts/test-i18n.cjs` 检查语言覆盖、占位符、英文单复数、Cookie 校验及首屏语言。

## ImageKit 小说接入

复制 `.env.example` 为 `.env.local`，填写 ImageKit 服务端环境变量：

```env
IMAGEKIT_PRIVATE_KEY=你的私钥
IMAGEKIT_URL_ENDPOINT=https://ik.imagekit.io/你的账号
IMAGEKIT_NOVEL_PATH=/novels/
IMAGEKIT_SIGNED_FILES=true
IMAGEKIT_CACHE_SECONDS=60
```

将每部小说以一个 UTF-8 TXT、MD 或 MDX 文件上传到 ImageKit 的 `/novels/` 目录。网站支持两种组织方式：一个文件包含整部小说，或沿用原有的“小说文件 + `chapters` 子目录”结构。文件可以使用以下格式：

```text
---
title: 燕云有信
description: 历史穿越
status: 连载中
---

作品简介内容……

第一章 雨夜旧札

第一章正文……
```

网站会自动读取目录中的 TXT、MD、MDX 文件，拆分章节并生成小说目录。新增小说只需要上传新的文件，不需要修改代码或重新提交小说内容。远程 MD/MDX 按安全的纯文本规则解析，不会执行其中的 JSX 组件。

完整格式规则请参考 [NOVEL_CONTENT_RULES.md](./NOVEL_CONTENT_RULES.md)。

## ImageKit 音频接入

音频与小说放在同一个 ImageKit 账号，在根目录新建 `media`，与 `novels` 并列：

```text
/
├── novels/
└── media/
    ├── 20261006/
    │   ├── 1_雨夜旧札.mp3
    │   ├── 2_榷场死人.wav
    │   └── 10_新的一天.mp3
    └── 202601006/
        └── 1_声音记录.mp3
```

日期目录推荐使用 `YYYYMMDD`。已有三位月份的旧目录（如 `202601006`）会按 `2026.10.06` 显示并参与日期排序。目录下支持 MP3 和 WAV，文件名为 `正整数_标题.mp3` 或 `正整数_标题.wav`，扩展名不区分大小写。两种格式可混放，同一天按数字顺序排列（1、2、10），日期从新到旧排列。每个目录只读取其直接下级文件。页面显示作品标题，重复编号时按文件名排序。

沿用小说的 `IMAGEKIT_PRIVATE_KEY` 和 `IMAGEKIT_URL_ENDPOINT`，可选新增变量：

```env
IMAGEKIT_MEDIA_PATH=/media/
```

不设置时默认读取 `/media/`。私有音频与小说一样使用 `IMAGEKIT_SIGNED_FILES=true`。上传时保留文件名及编号，音频应处于已发布状态。以后新增音频只需上传 MP3 或 WAV，WAV 建议使用浏览器广泛支持的 PCM 编码；目录缓存默认 60 秒，刷新页面即可看到，不需要再次改代码或部署。

从顶部“声音”进入 `/media`。最新一天的作品直接展示，往期按日期展开。首次播放需要手动点击，点选音频后显示底部播放栏，点击当前音频可以暂停或继续。底部紧凑播放栏提供播放/暂停和进度拖动；展开“播放设置”可使用上一段/下一段、快进/快退、倍速、音量、自动连播、循环和定时停止。列表续播顺序与目录展示顺序相同，播完一个日期后继续下一个日期。关闭自动下一首会在当前音频结束后停止，单曲循环独立生效。

“定时停止”可设置 1–360 分钟，到点暂停当前音频，支持取消及重新定时；暂停期间倒计时仍继续。关闭页面后定时器结束。手机后台计时和自动续播受浏览器及系统限制。

音频由浏览器直接从 ImageKit 播放，每次选择音频取得新的签名地址（有效期 24 小时），支持 ImageKit 的分段请求和拖动进度。列表不包含音频文件内容，`preload="none"` 避免提前加载整份列表；单个约 10 MB 的文件不经过 Vercel 函数响应。

## 显示与加载体验

- 手机导航提供首页、小说、声音、关于并标记当前页面；导航预加载目标页面，较慢的切换显示细进度条，目录使用加载占位。
- 简介、章节及音频分组支持展开收起，动效尊重系统的“减少动态效果”设置。
- 阅读设置在手机与桌面均可直接打开，支持跟随主题、白色、护眼绿和护眼黄；背景配色作用于全站，切换页面保持所选颜色；浅色背景同步使用明亮文字主题，右上角明暗按钮可恢复跟随主题。
- 小说目录刷新时限制并发下载并复用同一轮请求，每次远程请求最多等待 12 秒。读取失败时保留最近 10 分钟内上次完整目录并提示；没有完整缓存时会明确说明目录不完整，失败结果不写入完整目录缓存，可立即重试。
- 播放器区分就绪、加载、缓冲、播放、暂停、结束及失败；切换音轨重置进度，加载超过 20 秒提供重试提示。

回归检查：`node scripts/test-media.cjs`、`node scripts/test-catalog.cjs`、`pnpm lint`、`pnpm exec tsc --noEmit`。
