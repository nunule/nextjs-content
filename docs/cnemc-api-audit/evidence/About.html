  • 1、发布依据：根据《环境空气质量标准》（GB 3095-2026）、《环境空气质量指数（AQI）技术规定》（HJ 633-2026）的有关要求，发布全国城市空气质量状况。
  • 2、发布内容：评价时段、城市和点位名称及位置、污染物浓度及空气质量分指数、空气质量指数、首要污染物及空气质量级别、健康指引及建议采取的措施。
  • 3、数据来源：国家城市环境空气质量监测点位的自动监测数据。
  • 4、其他说明：
  • （1）实时发布数据用于向公众提供健康指引，不直接用于空气质量达标状况的评价。
  • （2）每小时更新发布数据，由于数据传输及处理需要一定时间，平台整点时刻后20分钟发布监测数据。
  • （3）点位监测仪器设备维护、故障、停电时，无监测数据。
  • （4）根据《“十五五”国家城市环境空气质量监测点位设置方案》要求，部分站点SO2、CO长期稳定达标，不再开展该指标监测，发布数据中以“/”标识。
《环境空气质量标准》（GB 3095-2026）中规定的空气污染物基本项目为二氧化硫（SO2）、二氧化氮（NO2）、一氧化碳（CO）、臭氧（O3）、可吸入颗粒物（PM10）、细颗粒物（PM2.5）六项。其中，SO2、NO2、CO、O3浓度为参比状态（大气温度为298.15 K，大气压力为1013.25 hPa）下的浓度，PM10、PM2.5浓度为实况状态（监测时的实际大气温度和压力）下的浓度。

1、空气质量指数（AQI）：
定量描述空气质量状况的无量纲指数。AQI的数值越大、空气质量级别越高，说明空气污染状况越严重，对人体的健康危害越大。AQI为SO2、NO2、CO、O3、PM10、PM2.5六项污染物的空气质量分指数（IAQI）的最大值。
2、空气质量级别：
根据AQI指数，分为优（1 ~ 50）、良（51 ~ 100）、轻度污染（101 ~ 150）、中度污染（151 ~ 200）、重度污染（201 ~ 300）和严重污染（>300）六个级别。
3、首要污染物：
AQI大于50时，IAQI最大的污染物为首要污染物。若IAQI最大的污染物为两项或两项以上时，并列为首要污染物。
