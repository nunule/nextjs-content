# 环境栏目

入口：`/environment`，支持 `#standards`、`#pollutants`、`#exercise` 直接定位子页签。

页面复用全站语言和主题。新增内容覆盖中英文，子页签、浓度、对照标准及运动选择在切换语言时保留。图表与图解使用 CSS / SVG，无图片或图表库依赖。

标准解读采用宽版图表布局：同一污染物、单位及平均时长下的全部可用标准默认显示。浓度滑块、数值输入、色带点选 / 拖动及分界值按钮同步更新各行等级与分指数。色带长度按实际浓度比例绘制，近邻阈值在窄屏分行显示。默认 PM2.5 演示浓度为 141 µg/m³。七套体系始终保留在紧凑对照表中，手机可横向浏览表格，选中体系后查看单条说明及官方来源。

不符合当前口径的体系显示原因；有可用的其他时长时，可点击提示直接切换。例如 PM2.5 的 24 小时图显示中、美、英、印，欧洲 EEA 在小时图中与中国对照。加拿大和日本保留独立解释，不推算通用单项 AQHI 或综合 AQI。

02 污染物详解复用其他页签的紧凑顶部、黑白选中状态、白色卡片及细边框。桌面六种污染物在一行选择，正文左侧图解、右侧五项要点；窄屏自动变为图解与说明上下排列。粒径图按 PM2.5、PM10 的顺序展示 1:4 直径比例，臭氧和气体保留形成过程及暴露路径示意。标准图入口继续传递当前污染物。

## 数据与计算

- `lib/environment/data.ts`：七套体系的定义、分级、人群、健康建议、六种污染物和可对照阈值。
- `lib/environment/constants.ts`：来源、核对日期、默认状态与图例。
- `lib/environment/calculations.ts`：按污染物、时长过滤；浓度分级与中美分指数计算。
- `lib/environment/messages.ts`：页面界面文案；全站导航与 metadata 位于原有国际化字典。
- `lib/environment/standards-overview.ts`：七套体系的紧凑综合判定摘要。
- `components/environment/standards-panel.tsx`：浓度图交互、分界标签和七套体系对照。

核对日期为 2026-10-09。各记录保留官方 URL。中国采用 HJ 633—2026 表 3（PM2.5 日均分指数 100 对应 60 µg/m³，PM10 对应 120 µg/m³），计算指数向上进位。美国颗粒物按 EPA May 2026 表 6 截断浓度、插值并四舍五入。英国十个指数映射为四个健康等级；欧洲和印度浓度图只展示对应类别。

小时、8 小时、24 小时和 15 分钟口径分别呈现；24 小时日历均值和滚动均值仍有窗口区别。没有自动转换平均时长，也没有将 ppm / ppb 气体数值直接换成 µg/m³。中国小时 SO₂ 和 8 小时 O₃ 超过表内上限时，分别按原文固定分指数为 200、300。

加拿大 AQHI 通常联合计算健康风险，野火烟雾另有小时颗粒物调整方法；本页不提供通用单污染物换算。日本 PM2.5 注意指引与 AQI 单独解释，因此不纳入共享 AQI 浓度色带。页面使用统一图解配色，并明确不把不同标准的同色、同数值解释为相同健康风险。

## 户外运动

03 户外运动采用与全站一致的黑白控件、白色卡片和细边框。默认演示为中国大陆 PM2.5 小时均值 32 µg/m³，按欧洲 EEA 普通人群解释，直接展示散步、轻松慢跑和剧烈运动三种建议。测量地区与参考标准独立选择，支持欧洲 EEA、美国 EPA 颗粒物指引和日本环境省 PM2.5 注意指引。

平均时长与所选标准不符时显示待补充数据，不生成运动结论。切换数据时长会清空数值并要求重新填写；不会把小时浓度换成日均。日本要求预计日均，低于 70 µg/m³ 不显示运动安全许可。下方三套指引为各自平均值都等于所填数值的假设对照，并明确不是时间换算。

欧洲可补充同一时段的 PM10、O₃、NO₂、SO₂，美国可补充 PM10，按已填项目中的最差等级提供建议。美国气体未纳入，页面不将这些结果标为完整综合 AQI。症状选择只影响有条件的活动解释，不改变空气等级，不推算安全分钟数。判定依据可展开，包含官方健康指引、人群定义和来源。页面支持英文、深色模式和手机布局。

- `lib/environment/exercise.ts`：时长匹配、多污染物分级及运动范围解释。
- `lib/environment/exercise-messages.ts`：户外运动界面的双语文案。
- `components/environment/exercise-panel.tsx`：输入、运动卡片、依据及假设对照。

首版为标准知识和运动参考，不含定位、实时监测、预报 API 或提醒。浓度滑块明确标注为示例数据。

## 验证

```sh
node scripts/test-environment.cjs
node scripts/test-i18n.cjs
node node_modules/typescript/bin/tsc --noEmit
npm run lint
npm run build
```

阈值检查包含中美等级边界、EPA 小数截断、不同平均时长隔离、图表连续性、封顶规则、运动建议范围和双语完整性。更新官方标准时，应一起更新阈值、版本、来源和核对日期，再运行这些检查。
