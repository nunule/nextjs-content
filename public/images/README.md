# 图片目录

图片按照“年份/月”两级目录存放，文件名使用八位数字日期：

```text
public/images/
└── 2026/
    └── 08/
        └── 20260813.jpg
```

支持 `.avif`、`.gif`、`.jpeg`、`.jpg`、`.png`、`.svg` 和 `.webp`。

对应的图片展示页 URL 为：

```text
/image/2026/08/20260813
```

访问 `/image` 会优先打开当天的图片；当天没有图片时，会打开最近的一张图片。展示页下方会按“年份/月”显示图片目录，点击图片文件名即可查看对应图片。图片文件名可以带扩展名访问，例如 `/image/2026/08/20260813.jpg`。
